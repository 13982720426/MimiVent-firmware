# LitterBoxVentilation

ESP32-C3-DevKitM-1 的单 PIR 自动排风项目：检测到移动后启动继电器和 12V 风机；PIR 输出恢复 LOW 后延时关闭。状态灯已拆到 `StatusLed.h/.cpp`，主程序通过 `statusLedBegin()` 和 `statusLedUpdate()` 调用。

## 已实测的继电器状态（2026-10-21）

- 待机：RGB 蓝色呼吸，风机停止。
- PIR 触发：RGB 黄/橙色快速呼吸，风机运行。
- PIR 输出恢复 LOW 后约 10 秒：回到蓝色呼吸，风机停止。
- 继电器模块按高电平触发配置：`RELAY_ACTIVE_LOW = false`。触点接法为 `COM` 接 12V+、`NO` 接风机正极、`NC` 留空。
- 板上的蓝/黄小灯是 USB 串口 TX/RX 活动指示灯，不是可由 GPIO 控制的状态灯；程序串口日志会在状态变化时产生发送活动。用于表达风机控制状态的是 GPIO8 上的板载 WS2812 RGB 灯。

## 引脚

| 信号 | ESP32-C3 引脚 |
|---|---:|
| PIR OUT | GPIO4 |
| 继电器 IN | GPIO5 |
| 板载 WS2812 RGB 灯 | GPIO8 |
| 公共地 | GND |

PIR 与 ESP32 共地。PIR 的 OUT 高电平必须在 ESP32 GPIO 可承受范围内（不高于 3.3V）。继电器 IN 必须确认支持 3.3V 控制，不能把 12V 接到 GPIO。

## 初次调试

1. 确认继电器模块线圈为 12V，触点接 `COM` 与 `NO`；`NC` 留空。确认风机电源关闭时继电器不吸合。
2. Arduino IDE 选择 `ESP32C3 Dev Module`、实际 USB 串口；Flash Size 设为 `4MB (32Mb)`，Partition Scheme 设为 `Default 4MB with spiffs`。
3. 打开 `LitterBoxVentilation.ino` 并上传。串口监视器设为 115200 baud。
4. **台架测试时先断开风机正极并绝缘线头**，再给 ESP32、PIR 和继电器控制模块供电。当前 `DEMO_MODE = true`：触发 PIR 后继电器吸合；PIR 输出恢复 LOW 后至少再运行 10 秒，且风机总运行时间不少于 10 秒。风机正极断开时风机不会转。
5. 当前根据实测设为高电平触发（`RELAY_ACTIVE_LOW = false`）。如果风机仍与状态灯相反，断电核对继电器模块触发方式后再调整此项。
6. 当前是 demo 配置：PIR 每 10ms 读取一次，停止触发后延时 10 秒，且保证至少运行 10 秒。正式使用前将代码中的 `DEMO_MODE` 改为 `false`，会切换到 50ms 读取间隔、3 分钟延时和 30 秒最短运行时间。

## 状态灯

- 每次启动先闪烁 3 次绿色，表示程序已开始运行。
- 待机时缓慢蓝色呼吸。
- PIR 触发、风机运行时快速且更亮的黄/橙色呼吸；延时结束、风机关闭后恢复慢速蓝色呼吸。

## 供电注意

- 按你现在确认的接法，DCP3512 的 3.3V 输出接开发板 `3V3`，GND 共地。不要把 5V 接到 `3V3`。
- DCP3512 的 12V 输出需要能承受风机启动电流和继电器负载；12V 适配器也要有余量。
- 接线或改线前先断开电源。首次联调先断开风机正极，确认继电器控制逻辑及常态为 OFF 后，再断电接回风机。

本版本不包含 Wi-Fi、蓝牙、第二个 PIR 或手机控制。

> PIR 模块自身检测后保持 HIGH 的时长由模块电位器控制。软件轮询间隔只决定 ESP32 多久读取一次引脚，不能缩短 PIR 模块的硬件保持时间。串口会在 PIR 电平变化和风机开关时输出带时间戳的日志。
