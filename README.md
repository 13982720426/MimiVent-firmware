# LitterBoxVentilation

ESP32-C3-DevKitM-1 单 PIR 自动排风固件，包含本地手机网页控制台。开机默认 PIR 自动感应；手机页面可查看 PIR/风机状态，临时强制开/关均可设定时长，另有需要二次确认的持续关闭锁。

## 当前硬件与已验证逻辑

- PIR OUT：GPIO4；继电器 IN：GPIO5；板载 WS2812：GPIO8。
- 继电器使用高电平触发（`RELAY_ACTIVE_LOW = false`）；`COM` 接 12V+，`NO` 接风机正极，`NC` 留空；风机负极回 DCP3512 GND。
- 待机蓝色呼吸灯、风机关闭；PIR 触发后橙色快速呼吸灯、风机开启；PIR LOW 后延时关闭。
- 第二个 PIR 暂不接入，GPIO3 目前不参与程序。

## 手机网页控制台

本版使用 ESP32 自建 Wi-Fi 热点（AP），不依赖路由器和外网，也没有额外网页库依赖：

1. Arduino IDE 选择 `ESP32C3 Dev Module`，Flash Size 设为 `4MB (32Mb)`，Partition Scheme 设为 `Default 4MB with spiffs`。
2. 上传项目目录中的 `LitterBoxVentilation.ino`。
3. 手机连接 Wi-Fi：`VentBox88`，密码：`VentBox88`。
4. 浏览器访问 `http://192.168.4.1`。

连接 ESP32 自建热点期间，手机通常无法同时通过该 Wi-Fi 上网；这是 AP 模式的正常表现。当前页面和设备状态只在手机与 ESP32 的本地连接中可用，不提供云端远程访问。

页面提供以下控制：

- **自动感应**：PIR HIGH 时开风机；PIR LOW 后等待设定延时，并满足最短运行时间后关风机。
- **定时排风**：强制运行 30 秒、1 分钟、5 分钟或 10 分钟，到时自动回到感应模式。
- **临时暂停**：暂时停机 30 秒、1 分钟、5 分钟或 10 分钟，到时自动回到感应模式。
- **持续关闭**：红色按钮先进入确认框，再点击确认；持续关闭会忽略 PIR，直至手动恢复自动模式或设备重启。
- **立即恢复自动感应**：不等待定时结束，立即返回自动控制。

“自动感应”主按钮放在临时排风选项上方。点击会立即关闭风机并取消当前临时模式；如果 PIR 当时仍保持 HIGH，会忽略这一次已触发信号，等 PIR 回到 LOW 后重新进入正常感应，避免风机刚关又被同一轮信号立即打开。下一次 PIR 新触发会照常启动风机。

设备每次上电默认进入自动感应。持续关闭锁定只保存在运行内存中，手动恢复自动或设备重启后解除；重启不会遗留“持续关闭”状态。

页面每秒刷新真实状态：网络在线、PIR 电平、当前风机状态、运行时长、延时停止倒计时和当前模式。网页完全本地内嵌，不引用外部 CDN。

“自动感应”是页面上方的主操作按钮，启用时显示勾选态和“已启用自动感应”；状态卡片采用静态样式，只有定时控制、自动感应和危险操作使用明显按钮样式。底部显示热点名称、密码和控制地址，便于手机连接。

热点名和密码都在 `LitterBoxVentilation.ino` 顶部的“Wi-Fi 热点配置”区修改。ESP32 SoftAP 密码必须至少 8 个字符。

2026-10-21 已通过本机 Arduino CLI 编译，并向当前连接的 ESP32-C3 执行烧录。烧录后仍需用手机按上面的热点和地址打开页面，完成实际交互检查。

## 时序配置

`LitterBoxVentilation.ino` 中 `DEMO_MODE` 默认设为 `true`：

- 演示：PIR LOW 后延时 10 秒；最短运行 10 秒。
- 正式：设为 `false` 后，PIR LOW 延时 3 分钟；最短运行 30 秒。

PIR 模块自身输出 HIGH 的保持时间由模块电位器控制，软件延时不会缩短它。正式使用前需按实际需求调整时序。

## 建议的网页联调顺序

1. 第一次验证网页时，让风机 12V 正极保持断开并做好绝缘，给 ESP32、PIR 和继电器控制侧供电。
2. 手机连接 `VentBox88` 并打开 `http://192.168.4.1`，检查页面能显示在线、PIR 状态和模式。
3. 测试一个短时排风和短时暂停选项，确认倒计时结束后自动恢复感应；再测试持续关闭按钮的二次确认和“立即恢复自动感应”。
4. 断电后再接回风机正极，重新上电测试自动排风和延时停止。

## 编译

本机验证命令：

```sh
arduino-cli compile --fqbn esp32:esp32:esp32c3 LitterBoxVentilation
```

依赖：ESP32 Arduino core 自带的 `WiFi`、`WebServer`，以及项目已有的 `Adafruit NeoPixel` 库。
